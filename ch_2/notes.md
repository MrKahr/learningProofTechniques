# Logic 
## Quantifier 
A quantifier is an operator used to specifiy how many elements of some universe U satisfy a formula or a property. 

There are two quantifiers that frequently used in first order logic.

$\exists x$ - in universe of discourse, there is an element 

$\forall x$ - for all elements in the universe of discourse, it is the case that

Note that it is possible to negate quantifiers. 

### Natural language mappings
$\exists$ - there is at least 1, someone did, nobody is (negation of $\exists$), 

$\forall$ - everyone, all x do, every x does

### Quantifier negation laws 
$\neg x P(x) \equiv \forall x \neg P(x)$

$\neg \forall x P(x) \equiv \exists x \neg P(x)$

Combined with other equivalences, laws (including DeMorgan), we can begin to negative statements as equivalent positive statements.
